📦 Formato de Trama

Todas las comunicaciones usan tramas delimitadas por corchetes en formato texto:

[KM*DEVICEID*SERIAL*LEN*CONTENT]
Campo Descripción Ejemplo
DEVICEID Identificador del reloj WATCH001
SERIAL Número de serie (echado en respuesta) 0042
LEN Longitud de CONTENT en hex (4 dígitos) 0006 (6 bytes)
CONTENT COMANDO[,arg1,arg2,...] INIT o UD,lat,lon

🔄 Ejemplo de Intercambio

Reloj → Servidor:

[KM*WATCH001*0001*0004*INIT]

Servidor → Reloj:

[KM*WATCH001*0001*0006*INIT,1]

⚡ Fragmentación TCP

Manejo Automático: TCP es un stream de bytes — una trama puede llegar en múltiples eventos data, o múltiples tramas en un evento. ConnectionHandler mantiene un buffer por conexión y scanea [...] para extraer tramas completas.

🎛️ Command Handler Registry — Patrón Command Pattern

⚡ ¿Por qué Command Pattern es la Mejor Opción?

El patrón Command Pattern con una Map<string, ICommandHandler> es superior a alternativas como if-else chains o switch statements:

⚡ Complejidad O(1) Map lookup instant. if-else/switch = O(n)
📈 Escalabilidad Agrega comandos sin modificar core logic
🧪 Testabilidad Cada handler es independiente, fácil de mockear
🔧 Mantenibilidad Responsabilidad única por comando

🔄 Ciclo de Vida de un Comando

1. Trama llega en TCP
[KM*WATCH001*0042*0004*INIT]

2. FrameParser.parseTrama()
→ Extrae: command="INIT", args=[]

3. CommandRegistry.dispatch()
→ handlers.get("INIT") → O(1)

4. InitHandler.handle(ctx)
→ Retorna: "INIT,1" (lógica pura)

5. ConnectionHandler escribe respuesta
→ socket.write([KM*WATCH001*0042*0006*INIT,1])

💡 Principios de Diseño

✓ Separación de Responsabilidades: Handlers contienen lógica, no I/O. ConnectionHandler maneja socket.write()
✓ Open/Closed Principle: Abierto para extensión (agregar handlers), cerrado para modificación (sin tocar registry core)
✓ Testability First: Mock handler retorna null o respuesta — sin necesidad de socket real

📋 Comparación con Alternativas

💻 Implementación TypeScript

// Interfaz central — contrato para todos los handlers
interface ICommandHandler {
  handle(ctx: HandlerContext): string | null;
}

// Registry con Map O(1)
class CommandRegistry {
  private handlers: Map<string, ICommandHandler>;
  
  dispatch(cmd: string, ctx: HandlerContext): string | null {
    const handler = this.handlers.get(cmd) 
      || this.handlers.get('*'); // fallback
    return handler.handle(ctx);
  }
}

// Handler concreto — ejemplo
class InitHandler implements ICommandHandler {
  handle(ctx: HandlerContext): string {
    logger.info('[INIT] Watch connected', {
      deviceId: ctx.trama.deviceId
    });
    return 'INIT,1'; // Respuesta pura, sin I/O
  }
}
🎯 Contrato Fundamental: Handlers retornan string | null — NUNCA escriben directamente al socket. ConnectionHandler es responsable de todo I/O. Esto permite testear handlers con 0 dependencias de red.

☁️ Infraestructura AWS

🌍 Internet → Relojes Qulip (TCP :9000)
↓
Network Load Balancer (NLB) — Layer 4
↓
Subnets Privadas (AZs: a, b)
↓
ECS Fargate Tasks (2 réplicas) — :9000
Importante: NLB opera en Layer 4 y preserva la IP del cliente (reloj). No tiene SG propio, por lo que el SG de ECS debe permitir 0.0.0.0/0:9000.
Escalabilidad: Las tareas ECS se distribuyen en AZs para alta disponibilidad. NLB balancea tráfico automáticamente.

🔄 Graceful Shutdown

Proceso:
1. SIGTERM/SIGINT recibido
2. TcpServer.close() → detiene nuevas conexiones
3. Espera a conexiones activas (timeout 30s)
4. process.exit(0) on success | process.exit(1) on timeout

💡 Decisiones Clave de Arquitectura

1️⃣ TCP Server Nativo (sin Express)

net.Server nativo permite optimizar para protocolo binario raw, sin overhead HTTP.

2️⃣ Command Pattern con Handler Registry

Dispatch O(1) mediante Map. Facilita agregar nuevos comandos sin modificar código central.

3️⃣ Handlers retornan strings (no escriben socket)

Separación de concernimientos: lógica de negocio ≠ I/O. Facilita testing.

4️⃣ Manejo automático de fragmentación TCP

ConnectionHandler scanea [...] en buffer acumulado — maneja múltiples eventos data.

5️⃣ NLB Layer 4 → SG permite 0.0.0.0/0

NLB preserva IP de cliente pero no tiene SG propio. El SG ECS debe permitir todos los IPs.
